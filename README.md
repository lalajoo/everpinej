# 페누리 (Penuri)

회원가입 없이 디지털 온누리 가맹 약국과 페이스사인 확인 상태를 찾는 모바일 웹서비스입니다. 기존 everpinej.com의 정적 HTML/CSS/JavaScript, GitHub Pages 구조를 그대로 사용합니다. 새 프레임워크·서버·유료 API·지도 SDK가 없습니다.

## 실행과 배포

Node.js 20 이상, Python 3.10 이상. 외부 패키지 설치는 필요 없습니다.

```sh
npm run dev
# http://127.0.0.1:4173/penuri/
npm test
npm run build
```

`dist/penuri/`를 기존 사이트 루트의 `penuri/`에 복사하면 `/penuri/`에서 서비스됩니다. GitHub Pages는 `/penuri`를 `/penuri/`로 연결합니다. 기존 홈페이지의 HTML·스타일·메뉴·다른 앱은 수정하지 않습니다. 실배포 저장소는 `lalajoo/everpinej`, Pages 소스는 `main`의 루트입니다.

## 파일

| 경로 | 용도 |
| --- | --- |
| `penuri/index.html`, `styles.css`, `favicon.svg` | 모바일 화면, 접근성, SEO·Open Graph |
| `penuri/app.mjs`, `core.mjs` | 검색·필터·거리순·공유·행사 종료·제보 |
| `penuri/config.json` | 행사 기간·혜택·확인 유효기간·제보 수신 설정 |
| `penuri/data/manifest.json`, `index-*.json`, `region-*.json` | 공식 자료 기반 검색 색인과 지역별 상세 파일 |
| `scripts/download_official.py` | 공공데이터포털 공개 다운로드 버튼의 파일 수집 |
| `scripts/import_data.py` | CSV/ZIP 정규화·중복 정리·주소 결합·관리자 확인 반영 |
| `scripts/build.mjs`, `serve.mjs` | 정적 배포 파일 생성 및 로컬 실행 |
| `data/admin/verifications.json` | 수동 페이스사인 확인 기록 |
| `tests/` | 검색·데이터·행사 경계·위치 권한 거부 테스트 |

## 데이터 출처와 현재 범위

- 온누리: [소상공인시장진흥공단 전국 온누리상품권 가맹점 현황](https://www.data.go.kr/data/3060079/fileData.do), **2026-07-31 기준**, 이용허락범위 제한 없음.
- 주소·전화·좌표: [건강보험심사평가원 전국 병의원 및 약국 현황](https://www.data.go.kr/data/15051059/fileData.do), **2026-09-30 기준**, 공공누리 제1유형(출처표시). 배포 화면 하단에도 출처를 표시합니다.
- 원본 225,803행에서 약국명에 ‘약국’이 있거나 취급품목이 ‘약국’인 행만 추출했습니다. 이름·지역·상점가를 정규화하여 동일 행을 정리한 **3,541건**을 수록했습니다. 실제 데이터만 서비스하며 테스트용 입력은 `tests/`에만 있습니다.
- 온누리 원본에는 도로명주소·전화·좌표가 없고 소재지는 시도 단위입니다. 두 공식 자료에서 정규화 이름과 지역이 각각 유일하게 일치하는 **2,089건**에만 심평원 주소·좌표를 연결했습니다. **1,452건**은 상세 주소 확인 필요로 남겼습니다. 동일 이름의 다른 점포를 임의로 합치지 않으며, 상점가 중복 등록 가능성은 남아 있습니다.
- 원본의 ‘전남광주’ 지역 분류는 보존합니다. 광주/전남 필터는 이 통합 분류를 함께 검색합니다. 주소가 연결되지 않은 매장은 시군구 검색에 누락될 수 있으므로 시도 또는 상점가 검색도 지원합니다.
- 온누리 자료의 디지털형 Y/N만 디지털 지원 여부로 사용합니다. 충돌/알 수 없는 값은 미확인입니다. 약국 이름에 ‘온누리’가 있다는 이유로 가맹 여부를 판단하지 않습니다.
- **페이스사인 확인 완료 기록은 현재 0건**입니다. 온누리 가맹 사실에서 페이스사인을 추정하지 않습니다. [공식 행사 페이지](https://campaign2.naver.com/npay/facesign_10/)에서 2026-10-12~11-30, 10%, 월 50,000포인트와 커넥트 단말기 조건을 2026-11-03 확인했습니다.
- [네이버 지역 검색 API 문서](https://developers.naver.com/docs/serviceapi/search/local/local.md)에는 페이스사인 가능 여부 필드가 없습니다. 공개된 확인용 API를 찾지 못하여 비공개 API나 지도 크롤링을 사용하지 않습니다.

## 데이터 갱신

공식 포털에서 파일을 직접 다운로드하거나 다음 명령을 사용할 수 있습니다. 포털이 인증·CAPTCHA를 요구하면 자동 다운로드는 중단하며, 직접 받은 파일을 그대로 가져올 수 있습니다.

```sh
python3 scripts/download_official.py --dataset 3060079 --output data/source/onnuri.csv
python3 scripts/download_official.py --dataset 15051059 --output data/source/hira.zip

# 날짜는 다운로드 시점이 아니라 실제 파일의 자료 기준일로 입력하세요.
python3 scripts/import_data.py \
  --onnuri data/source/onnuri.csv --date 2026-07-31 \
  --hira data/source/hira.zip --hira-date 2026-09-30
npm test
npm run build
```

CSV는 UTF-8(BOM 포함)·CP949를 지원하며 심평원 ZIP에서는 `2.약국정보서비스` CSV만 읽습니다. `--hira` 생략 시 주소·거리·전화는 표시하지 않고 주변 찾기 대신 지역 선택을 노출합니다. 데이터 갱신 시 기존 주소를 억지로 보존하지 않습니다.

정적 JSON은 파일명에 내용 해시를 포함합니다. 브라우저는 검색 색인과 결과에 필요한 지역 파일만 읽으며 원본 CSV를 내려받지 않습니다. 같은 세션에서는 지역 파일을 재사용합니다. 새 JSON을 먼저 올리고 manifest를 마지막에 교체하세요. 캐시된 이전 manifest를 위해 이전 해시 파일은 즉시 삭제하지 않습니다. 원본 CSV/ZIP은 `data/source/`에 보관하되 Git과 배포에서 제외합니다. 자료 기준일·원본 SHA-256·가져온 시각은 manifest에 남습니다.

## 페이스사인 확인 업데이트

`penuri/data/region-*.json`에서 대상 약국의 ID·이름·주소 또는 상점가를 확인한 뒤 `data/admin/verifications.json` 배열에 기록을 추가합니다. 아래 ID는 설명용 자리표시자이며 실제 약국 ID로 바꿔야 합니다.

```json
[
  {
    "id": "실제 약국 ID",
    "faceSignStatus": "verified",
    "faceSignVerifiedAt": "2026-11-03",
    "verificationSource": "관리자가 확인한 공식 링크 또는 매장 직접 확인 근거",
    "reviewedByAdmin": true
  }
]
```

상태는 `unknown`(미확인), `reported`(미검증 제보), `verified`(관리자 확인 완료), `unavailable`(불가 확인)입니다. verified/unavailable은 확인일·출처·관리자 검토 표시가 없으면 가져오기를 거부합니다. 미래 날짜, 존재하지 않는 ID, 중복 ID도 거부합니다. 직원 이름·개인 전화번호·환자 정보는 출처 기록에 넣지 마세요. 출처 텍스트는 방문자에게 공개됩니다.

다시 import→test→build→배포하면 반영됩니다. 원본 갱신으로 ID가 바뀌어 기록이 연결되지 않으면 오류로 알려주며 자동으로 다른 약국에 연결하지 않습니다. 온누리는 기본 180일, 페이스사인은 60일이 지나면 확인 배지를 제거하고 재확인 안내를 표시합니다. 이 기간은 운영상 정한 재확인 기준이며 공식 기관의 보증 기간이 아닙니다.

## 행사·제보 설정

`penuri/config.json`만 수정합니다.

- `event.endsAt`: 종료 경계. 현재 `2026-12-01T00:00:00+09:00`으로, 한국시간 11월 30일까지 유효합니다. 화면 종료일도 여기에서 계산합니다. 시작일 이전/종료 이후/수동 중단을 별도로 안내하고 약국 검색은 유지합니다.
- `event.enabled: false`: 조기 종료 시 즉시 안내 중단 설정. 페이지 새로고침 후 반영됩니다.
- `event.rewardPercent`, `monthlyLimit`: 공식 확인한 혜택 수치.
- `report.formUrl`: 관리자가 만든 HTTPS 외부 제보 폼 주소. 입력하면 제보 버튼이 이 폼을 엽니다. 폼은 약국명·지역·각 결제 가능 여부·선택 메모만 받도록 구성합니다.
- `report.email`: 외부 폼이 없으면 화면에서 제보 내용을 작성한 뒤 메일 앱으로 전송합니다. 기존 사이트 공개 문의 주소 `contact@everpinej.com`을 사용합니다. 실제 발송은 사용자가 메일 앱에서 수행하며 접수 완료로 오인시키지 않습니다. 사이트는 제보나 개인 위치를 서버에 저장하지 않습니다.

**필수 API 키·환경변수 없음.** 운영 시 외부 폼으로 바꾸려면 URL만 설정하면 됩니다. 위치 권한은 주변 찾기를 클릭한 경우에만 요청하고 거부/실패하면 지역 검색을 유지합니다. 좌표는 공유 URL에 포함하지 않습니다.

## 검증

- 자동 테스트: 실제 데이터 검색(제주·제주시·서울 강남구·부산 서면·약국명), 출처·좌표 일관성, 동명 점포 오결합 방지, 관리자 확인 검증, 오래된 기록, URL 왕복, 직선거리 정렬, 위치 권한 거부/시간 초과, 한국시간 행사 시작·종료·연장·중단.
- 브라우저 확인: 360·390·430px 및 1280px, 가로 넘침 없음, 입력 폰트 16px, 버튼 44px 이상, 제주 검색, 필터 빈 결과, 뒤로 가기 조건 복원, 더 보기, 없는 검색어 안내.
- Safari/Chrome/각 SNS 앱의 실제 기기별 전수 테스트는 하지 않았습니다. 기본 웹 API만 사용하며 위치·공유 API 지원 여부에 따라 지역 검색·링크 복사로 대체합니다.
- 네이버지도는 앱 설치 없는 웹 검색 링크를 사용합니다. 층·호수까지 포함한 긴 주소는 네이버에서 결과가 없어지는 사례를 확인해 지역+약국명으로 검색합니다. 동명 약국이 여러 곳이면 지도에서 선택해야 합니다.

운영 데이터에 페이스사인 확인 기록이 없으므로 현재 ‘둘 다 확인’ 결과가 없는 것은 정상입니다. 약국 전화 확인 또는 공식 매장 안내로 검증한 기록을 추가해야 해당 필터에 표시됩니다.
