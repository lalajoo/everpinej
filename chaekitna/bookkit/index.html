다른 사람의 책킷리스트로 시작해요

책있나에서 만든 책킷리스트를 누구나 올리고 받아갈 수 있어요. 마음에 드는 목록을 받아 앱에서 불러오면 한 번에 채워지고, 읽은 책은 내 색으로 칠하면 돼요.

내 책킷리스트 올리기 받는 방법

좋아요 많이 받은 책킷리스트다른 독서가들이 가장 많이 담아 둔 목록이에요

내가 올린 목록 (이 브라우저에만 기억돼요)

책있나로 가져오는 방법

  1. 마음에 드는 목록을 열고 파일 받기를 눌러요. 아이폰은 공유 창에서 ‘파일에 저장’을 고르고, 안드로이드는 ‘다운로드’ 폴더에 저장돼요.
  2. 책있나 앱 → 책킷리스트 → 책 목록 나누기 → 받은 목록 가져오기를 눌러요.
  3. 저장한 책킷리스트_….json 파일을 고르고, 내용을 확인한 뒤 담으면 끝이에요.

내 목록을 올리는 방법

  1. 책있나 앱 → 책킷리스트 → 책 목록 나누기 → 내 목록 보내기 → ‘파일에 저장’.
  2. 이 페이지의 내 책킷리스트 올리기에서 그 파일을 골라 올려요.

파일에는 책 제목·저자·ISBN만 담겨요. 색칠·읽음 기록은 공유되지 않아요.
