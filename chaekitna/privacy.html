책있나 개인정보처리방침

시행일: 2026년 9월 12일 · 플러스 관련 항목은 해당 기능 이용 시 적용

책있나(이하 “앱”)는 책의 ISBN 바코드를 읽어 가까운 공공도서관의 소장·대출 가능 여부를 안내하는 앱입니다. 개발자는 서비스에 필요한 최소한의 정보만 처리하며, 회원가입이나 로그인 없이 사용할 수 있습니다.

1. 처리하는 정보

  • 카메라: 책 뒷면의 바코드(ISBN)를 읽는 데만 사용합니다. 촬영된 이미지는 저장되거나 외부로 전송되지 않습니다.
  • 위치: 현재 위치에서 가까운 도서관을 정렬하기 위해 앱 사용 중에만 사용합니다. 위치는 기기 안에서만 계산에 쓰이며 서버로 전송되지 않습니다. 권한을 거부해도 지역을 직접 선택해 도서관을 확인할 수 있습니다.
  • 기기 안에 저장되는 정보: 최근 확인한 책, 내 책장에 저장한 책, 검색 반경 등 설정값
  • 광고 관련 정보: 결과 화면 하단 배너 광고를 위해 Google Mobile Ads SDK가 광고 식별자, 기기 정보, 대략적 위치, 광고 상호작용 및 사용 데이터를 처리할 수 있습니다. iOS 앱 추적 권한은 사용자의 선택이며 거부해도 앱을 이용할 수 있습니다. "광고 제거"를 구매하면 배너가 표시되지 않습니다.
  • 결제 정보: 인앱결제는 Apple이 처리하며 앱은 결제수단 정보를 수집하지 않습니다. 기존 광고 제거 구매 여부는 기기에 저장됩니다. 플러스 구독은 Apple 거래 식별자·상품·구독 상태·이용 기간을 서버에서 검증하고 보관합니다. 결제 카드 정보는 수집하지 않습니다.
  • 플러스 자동 확인: 사용자가 알림을 켠 책의 ISBN·제목, 선택한 도서관 코드·이름, 대출 상태·확인 시각·알림 이력, 설치 식별자, 알림용 기기 토큰을 서버에 저장합니다. Apple 푸시 알림 서비스와 구독 검증 서버를 이용합니다. 정확한 위치·카메라 영상은 이 기능에서 전송하지 않습니다.
  • 외부로 전송되는 정보: 소장·대출 여부 조회를 위해 책의 ISBN과 도서관 코드가 국립중앙도서관 도서관 정보나루 Open API로 전송됩니다. 개인을 식별할 수 있는 정보는 포함되지 않습니다.

2. 이용 목적

도서 정보 조회, 주변 도서관 안내, 소장·대출 가능 여부 표시, 사용자가 저장한 책 목록 관리에 사용합니다. 플러스 이용 시 구독 자격 검증, 자동 대출 상태 확인, 알림 전달과 서버 정보 삭제 요청 처리에 사용합니다.

3. 보관 기간

기기 안의 기록은 사용자가 앱을 삭제하거나 앱 내에서 지울 때까지 보관됩니다. 플러스 알림용 기기 정보는 마지막 연결 후 최대 90일, 조회 설정·구독 상태는 마지막 갱신 후 최대 400일, 세션은 최대 30일, 미발송 알림은 발생 후 최대 24시간 보관합니다. 플러스 화면의 ‘서버 알림 정보 삭제’로 서버의 관련 정보를 삭제할 수 있습니다. Apple 결제 기록은 Apple의 정책을 따르며, 서버 정보 삭제는 Apple 구독을 취소하지 않습니다.

4. 제3자 서비스

  • 국립중앙도서관 도서관 정보나루 Open API: 도서 정보, 도서관 정보, 소장·대출 가능 여부 제공 (참여도서관 목록은 CC BY 라이선스로 앱에 포함)
  • Apple 지도: 길찾기 버튼을 누를 때 외부 앱으로 연결
  • Google AdMob / Google User Messaging Platform: 광고 및 동의 관리
  • Apple StoreKit / App Store Server API / APNs: 인앱결제·구독 검증·푸시 알림
  • Amazon Web Services 서울 리전: 책있나 조회 서버 및 플러스 설정·구독 상태 보관

각 서비스의 정보 처리는 해당 사업자의 개인정보처리방침을 따릅니다.

5. 삭제 및 문의

기기 내 책 기록은 앱 삭제로 제거할 수 있습니다. 플러스 서버 기록은 앱의 ‘서버 알림 정보 삭제’에서 삭제할 수 있으며, 자동 재연결은 명시적인 구매 복원·구독 요청 전까지 중지됩니다. 구독 취소는 Apple 구독 관리에서 진행합니다. 개인정보 관련 문의는 lalajoo71@gmail.com으로 보내주세요.
