책있나 개인정보처리방침

시행일: 2026년 10월 25일

책있나(이하 “앱”)는 책의 ISBN 바코드를 읽어 가까운 공공도서관의 소장·대출 가능 여부를 안내하는 앱입니다. 개발자는 서비스에 필요한 최소한의 정보만 처리하며, 회원가입이나 로그인 없이 사용할 수 있습니다.

1. 처리하는 정보

  • 카메라: 책 뒷면의 바코드(ISBN)를 읽거나 사용자가 선택한 책 페이지를 사진 메모로 남기는 데 사용합니다. 바코드 스캔 영상은 저장하거나 외부로 전송하지 않습니다. 사진 메모 기능에서는 촬영하거나 앨범에서 선택한 사진의 사본, 형광펜 표시, 인식된 문장과 사용자가 적은 메모를 기기에 저장합니다. iPhone에서는 Apple Vision, Android에서는 Google ML Kit로 문장을 기기 안에서 인식하며, 사진이나 인식한 문장을 책있나 서버로 전송하지 않습니다. 원본 앨범 사진은 수정하지 않습니다.
  • 위치: 현재 위치에서 가까운 도서관을 정렬하기 위해 앱 사용 중에만 사용합니다. 위치는 기기 안에서만 계산에 쓰이며 서버로 전송되지 않습니다. 권한을 거부해도 지역을 직접 선택해 도서관을 확인할 수 있습니다.
  • 기기 안에 저장되는 정보: 최근 확인한 책, 내 책장에 저장한 책, 사진 메모 사본·형광펜 표시·인식 문장·입력 메모, 책킷리스트의 제목·책 목록·읽음 표시·색상, 검색 반경 등 설정값
  • 광고 관련 정보: 앱 화면 하단 배너 광고를 위해 Google Mobile Ads SDK가 광고 식별자, 기기 정보, 대략적 위치, 광고 상호작용 및 사용 데이터를 처리할 수 있습니다. iOS 앱 추적 권한은 사용자의 선택이며 거부해도 앱을 이용할 수 있습니다. "광고 제거"를 구매하면 배너가 표시되지 않습니다.
  • 앱 광고 효과 측정: 측정 기능이 포함된 버전에서 AppsFlyer를 통해 앱 설치·실행과 검색·도서관 조회 완료 여부, 발생 시각, 앱 설치 식별자, 앱·운영체제 버전 및 기기 모델 등 기술 정보를 처리합니다. 통신 과정에서 IP 주소와 이를 바탕으로 한 대략적인 지역 정보가 처리될 수 있으며, 보고서와 광고사 전달 데이터에서는 IP 주소를 가립니다. 광고 식별자(IDFA·Google 광고 ID)는 운영체제에서 허용된 경우에만 사용합니다. iOS 추적을 허용하지 않으면 광고 식별자를 사용하지 않는 익명 처리 및 Apple SKAdNetwork 집계 측정을 사용합니다. 검색어, 책 제목·ISBN, 독서기록·사진·메모 내용, 선택한 도서관, 정확한 위치, 이름·연락처는 이 측정 이벤트에 포함하지 않습니다. 카카오 광고로 유입된 설치와 설치 후 14일 이내의 검색·조회 완료 이벤트만 카카오에 전달하며, 이벤트 내용·금액·매출은 전달하지 않습니다. Meta(Facebook·Instagram) 광고의 설치 성과를 확인하기 위해 AppsFlyer에서 Meta로 설치 발생 정보와 운영체제에서 사용이 허용된 광고 기기 식별자 등 기여도 대조에 필요한 측정 정보를 전달할 수 있습니다. 이 설치 대조에는 Meta 광고 외의 광고 또는 자연 유입 설치도 포함될 수 있습니다. 앱 실행·검색·도서관 조회 완료 이벤트는 Meta 광고로 유입된 이용자에 한해 이벤트 발생 여부를 전달하며, 검색어·책 정보·독서기록·사진·메모 내용과 이벤트 매개변수·금액·매출은 전달하지 않습니다. 고급 데이터 공유 및 고급 매칭은 사용하지 않으며, 이메일·전화번호 등 연락처 기반 매칭은 하지 않습니다. 설정의 “광고 효과 측정”을 끄면 이후 AppsFlyer 측정을 중지합니다. 광고 제거 구매와 별도로 선택할 수 있습니다.
  • 결제 정보: 인앱결제는 이용 플랫폼의 스토어(Apple App Store 또는 Google Play)가 처리하며 앱은 결제수단 정보를 수집하지 않습니다. 기존 광고 제거 구매 여부는 기기에 저장됩니다. 플러스 구독은 Apple 거래 식별자 또는 Google Play 구매 토큰, 상품·구독 상태·이용 기간을 서버에서 검증하고 보관합니다. 구매 토큰은 구독 자격 확인과 구매 승인 처리에 사용됩니다. 결제 카드 정보는 수집하지 않습니다. 서버에서 검증된 유료 결제와 갱신 횟수를 구분해 집계합니다. 중복 집계를 막기 위한 거래 식별자의 해시와 결제일·플랫폼·상품·신규 또는 갱신 구분을 최대 400일 보관하며, 집계 보고서에는 구매 토큰이나 개인·책 정보를 포함하지 않습니다.
  • 무료·Pro 자동 확인: 사용자가 알림을 켠 책의 ISBN·제목, 선택한 도서관 코드·이름, 대출 상태·확인 시각·알림 이력, 임의의 설치 식별자, 알림용 기기 토큰을 서버에 저장합니다. 무료 알림 연결을 복구하기 위한 임의의 연결 키는 기기에 저장하고 서버에는 그 해시와 설치 식별자의 연결을 보관합니다. iPhone은 Apple APNs와 App Store Server API, Android는 Google Firebase Cloud Messaging과 Google Play Developer API를 이용합니다. Android 알림 등록 시 Firebase 설치 식별자와 푸시 토큰 등 알림 전달에 필요한 정보가 Google에 처리됩니다. 정확한 위치·카메라 영상은 이 기능에서 전송하지 않습니다.
  • 책킷리스트 공유: 사용자가 공유를 선택하면 책 제목·저자·ISBN을 담은 목록 파일을 선택한 앱이나 수신자에게 전달합니다. 사진 메모·읽음 색상·구매 정보·설치 식별자는 목록 파일에 포함하지 않습니다. 책있나 서버에 공유 목록을 업로드하거나 공개 목록을 자동 생성하지 않습니다.
  • 인기 책 집계: 설정에서 집계 참여를 켜 두면 사용자가 도서관 조회를 완료한 책의 ISBN을 책있나 서버로 보내 날짜별 조회 수를 집계합니다. 같은 기기의 같은 책은 한국 시간 기준 하루 한 번 집계하며, 중복 방지를 위해 책별·날짜별 무작위 확인값을 함께 보냅니다. 계정, 위치, 광고 식별자, 입력한 검색어와 연결하지 않습니다. 설정의 “인기 책 집계에 참여”를 끄면 이후 집계를 중지합니다.
  • 공용 조회 캐시: 조회 속도를 높이고 외부 API 호출을 줄이기 위해 입력한 검색어, ISBN, 선택한 지역·도서관 코드와 조회 결과를 서버에 임시 저장합니다. 이 캐시는 사용자·설치 식별자나 IP 주소와 연결하지 않습니다.
  • 외부로 전송되는 정보: 도서 검색과 소장·대출 여부 조회를 위해 검색어, 책의 ISBN, 조회할 지역·도서관 코드가 국립중앙도서관 도서관 정보나루 Open API로 전송됩니다. 개인을 식별할 수 있는 정보는 포함되지 않습니다.
  • 선택적 앱 이용 통계 (1.2.2부터): 최초에는 꺼져 있으며 사용자가 허용하거나 설정의 ‘앱 이용 통계 공유’를 켠 경우에만 Google Analytics for Firebase를 사용합니다. 화면·기능 사용 종류와 횟수(무료 기능 이용, Pro 안내 진입, 결제 시작·취소·실패·검증 완료 포함), 앱 실행·세션, 기기 종류·운영체제·앱 버전, 임의의 앱 인스턴스 식별자, IP에서 파생된 대략적인 지역, 스토어가 제공하는 앱 내 구매·구독 이벤트(상품·금액·통화 등)를 처리합니다. IP 주소는 지역 추정에 쓰일 수 있으나 Google Analytics에 기록·저장되지 않습니다. 이름·연락처나 자체 사용자 ID를 설정하지 않으며, Google Analytics의 IDFA·IDFV·Android 광고 ID 수집과 광고 개인 최적화는 사용하지 않습니다. 책 제목·ISBN·검색어·선택 도서관·독서기록·메모·사진·정확한 위치·결제수단 정보는 이 통계에 보내지 않습니다. 거절해도 모든 앱 기능을 이용할 수 있고 언제든 끌 수 있습니다. 이 설정은 기존 광고·광고 효과 측정 동의와 별개입니다.
  • 빌린 책·일정·백업 (1.2.2부터): 직접 등록한 대출·반납일, 도서관 방문일, 행사와 메모는 기기에 저장하고 반납 알림은 기기에서 예약합니다. 설정의 ‘내 데이터 보관’에서 책장·사진 메모·대출·일정·선택 도서관·일부 설정과 남아 있는 이전 책킷리스트 데이터를 ZIP 파일로 내보내거나 복원할 수 있습니다. 구독 증명·푸시 토큰·정확한 위치·통계 동의는 백업에서 제외됩니다. 내보낸 파일에는 개인 메모와 사진이 포함되므로 안전하게 보관하세요. 파일 앱·클라우드·공유 앱 등 사용자가 선택한 저장처로 전달되며 책있나 서버에 자동 업로드하지 않습니다. 복원 시 현재 데이터를 먼저 앱 안에 보관하고 선택한 백업으로 교체합니다. 복원 전 사본과 업데이트 전 메타데이터 사본도 기기에 저장하며 앱 삭제 시 함께 삭제됩니다. 자체 클라우드 동기화는 제공하지 않습니다.

2. 이용 목적

도서 정보 조회, 주변 도서관 안내, 소장·대출 가능 여부 표시, 사용자가 저장한 책 목록·사진 메모 관리와 기기 내 문장 인식, 전체 이용 기록에 따른 인기 책 안내에 사용합니다. 무료·Pro 알림 이용 시 자동 대출 상태 확인과 구독자의 자격 검증, 알림 전달과 서버 정보 삭제 요청 처리에 사용합니다. 광고 효과 측정 정보는 앱을 알리는 광고의 설치·이용 성과 분석과 광고 부정 이용 방지에 사용합니다.

동의한 앱 이용 통계는 앱 사용성과 기능 개선, 안정적인 서비스 운영을 위한 분석에 사용하며 광고 타기팅에 사용하지 않습니다. 월별 신착도서는 선택한 도서관에 해당 월에 등록된 자료를 확인하는 데 사용합니다.

3. 보관 기간

인기 목록은 오늘을 포함한 최근 7일의 책별 합계를 사용합니다. 날짜별 합계는 최대 8일, 중복 방지 확인값은 최대 2일 뒤 자동 삭제합니다. 기기의 확인값은 날짜가 바뀐 뒤 다음 집계 시 교체합니다. 개인을 구분할 수 없는 합계는 개인별로 분리해 삭제할 수 없습니다. 기기 안의 기록은 사용자가 앱을 삭제하거나 앱 내에서 지울 때까지 보관됩니다. 공용 조회 캐시는 검색어·소장·대출 조회 결과를 최대 24시간, ISBN별 도서 정보를 최대 30일 보관한 뒤 만료합니다. 무료 알림 연결 정보는 마지막 연결 후 최대 400일, 무료·Pro 알림용 기기 정보는 마지막 연결 후 최대 90일, 조회 설정·구독 상태는 마지막 갱신 후 최대 400일, 세션은 최대 30일, 미발송 알림은 발생 후 최대 24시간 보관합니다. 플러스 화면의 ‘서버 알림 정보 삭제’로 서버의 관련 정보를 삭제할 수 있습니다. 스토어 결제 기록은 Apple 또는 Google의 정책을 따르며, 서버 정보 삭제는 스토어 구독을 취소하지 않습니다.

광고 측정의 카카오 전달 기간(설치 후 14일)은 데이터 보관 기간과 다릅니다. AppsFlyer의 이용자 데이터는 해당 서비스의 보관 정책에 따라 원칙적으로 최대 24개월 처리될 수 있으며, 법령상 허용·필요한 경우 등 예외가 적용될 수 있습니다. 측정 중지는 이미 처리된 정보의 즉시 삭제를 뜻하지 않습니다. 관련 정보의 열람·삭제 요청은 아래 문의처로 접수할 수 있습니다.

Google Analytics의 이벤트·사용자 데이터 보관 설정은 기본 2개월로 운영하며 개인을 구분하지 않는 집계 보고서는 더 오래 남을 수 있습니다. 통계를 끄면 이후 수집을 중지하고 기기의 Analytics 데이터를 초기화하며 기존 서버 집계가 즉시 삭제되는 것은 아닙니다. 백업 파일은 사용자가 선택한 저장처에서 직접 삭제해야 합니다.

4. 제3자 서비스

  • 국립중앙도서관 도서관 정보나루 Open API: 도서 정보, 도서관 정보, 소장·대출 가능 여부 제공 (참여도서관 목록은 CC BY 라이선스로 앱에 포함)
  • 지도 앱: 길찾기 버튼을 누를 때 Apple 지도 등 기기에서 지원하는 외부 지도 서비스로 연결
  • Google AdMob / Google User Messaging Platform: 광고 및 동의 관리
  • Google Play Billing / Google Play Developer API: Android 광고 제거·플러스 구독 결제 및 검증
  • Google LLC / Google Analytics for Firebase: 동의한 앱 이용 통계 분석. 사용자가 동의한 후 이용 중 암호화된 통신으로 전달하며 미국 등 Google이 운영하는 해외 처리 인프라에서 처리될 수 있습니다. 수집 항목·목적·보관 기간·거절 방법은 위 내용을 따릅니다. Google 개인정보처리방침, Firebase 데이터 수집 안내
  • Google Firebase Cloud Messaging: Android 푸시 알림
  • Google ML Kit: Android 기기 내 문장 인식
  • Apple StoreKit / App Store Server API / APNs: 인앱결제·구독 검증·푸시 알림
