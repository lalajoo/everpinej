1. 앱이 처리하는 정보

ShaveLog는 사용자가 직접 촬영한 얼굴 사진, 촬영·기록 일시, 사진에서 계산한 부위별 명암·붉은색 참고 수치와 관찰 영역, 사진의 밝기·선명도 참고값을 처리합니다. 또한 사용자가 직접 선택한 사용감, 표준 얼굴형 템플릿, 면도기 이름·교체일·사용 횟수·교체 기준을 처리합니다. 이 중 얼굴 사진과 아래 2항의 얼굴 위치·특징점·촬영 방향을 이 방침에서 ‘얼굴 데이터’라고 합니다.

2. 얼굴 데이터의 처리 항목과 목적

촬영 직후 Apple의 기본 Vision 프레임워크가 iPhone 안에서 얼굴의 경계 위치, 눈·눈썹·코·입술·얼굴 윤곽의 2차원 특징점, 촬영 방향(yaw·pitch)을 일시적으로 확인합니다. 이 정보는 촬영 자세와 얼굴 존재 여부 확인, 사진의 관찰 영역 구분, 부위별 명암·붉은색 참고 수치 계산에만 사용합니다. Vision이 반환한 얼굴 위치·특징점·촬영 방향 자체는 분석이 끝난 뒤 저장하지 않습니다.

ShaveLog는 얼굴 데이터를 신원 식별, 사용자 인증, 다른 얼굴과의 대조, 광고, 추적 또는 프로파일링에 사용하지 않으며 Face ID 템플릿이나 생체인식용 얼굴 벡터를 만들지 않습니다. 화면의 3D 얼굴은 사용자가 네 가지 중 선택한 표준 얼굴형 템플릿으로, 촬영한 얼굴을 3D로 복원한 것이 아닙니다. 사진 참고 수치는 의학적으로 검증된 평가, 잔수염 진단, 피부 질환·자극 진단 또는 면도날 마모 검출 결과가 아닙니다.

3. 저장 위치와 보관 기간

저장하기를 완료한 얼굴 사진은 정규화된 JPEG 파일로, 계산된 참고 수치와 기록·설정은 앱 데이터로 사용자의 iPhone 내 ShaveLog 전용 앱 저장 공간에만 보관합니다. 저장하기 전의 원본 촬영 파일은 분석 중에만 임시로 사용하며, 저장 완료·재촬영·취소 또는 화면 종료 시 삭제합니다. 저장된 얼굴 사진과 참고 수치는 사용자가 해당 기록을 삭제하거나, 같은 날짜의 기록으로 교체하거나, 모든 기록 및 사진을 삭제하거나, 기기에서 앱을 삭제할 때까지 보관합니다. 개발자가 정한 별도의 서버 보관 기간은 없습니다.

앱 전용 데이터는 사용자의 iOS·iCloud 또는 컴퓨터 백업 설정에 따라 운영체제 백업에 포함될 수 있습니다. 이는 ShaveLog 또는 개발자 서버로의 전송이 아니며 해당 서비스의 정책과 사용자 설정이 적용됩니다. 앱에서 삭제한 정보의 기존 백업 사본은 즉시 삭제되지 않을 수 있으며 백업의 보관·삭제는 사용자가 해당 OS 또는 서비스 설정에서 관리합니다.

4. 외부 전송·공유·제3자 제공

ShaveLog는 얼굴 사진, Vision 얼굴 위치·특징점·촬영 방향 또는 계산된 참고 수치를 개발자나 외부 서버로 전송하지 않습니다. 얼굴 데이터를 제3자와 공유·판매·대여·공개하지 않습니다. 처리에는 iPhone에 포함된 Apple Vision 프레임워크만 사용하며, 타사 얼굴 분석 서비스·광고·분석·추적 SDK를 사용하지 않습니다. 계정과 로그인 기능도 없으므로 개발자는 기기 속 얼굴 데이터나 기록을 원격으로 열람·복구할 수 없습니다.

5. 권한

카메라 권한은 사용자가 면도 사진을 촬영할 때만 필요합니다. 거부하면 촬영은 사용할 수 없지만 예시 리포트와 기존 기록은 볼 수 있습니다. 권한은 iOS 설정에서 변경할 수 있습니다. 마이크는 사용하지 않습니다. 현재 버전은 사진 보관함에서 가져오거나 보관함에 저장하는 기능이 없으며 사진 보관함 권한을 요청하지 않습니다.

6. 열람과 삭제

기록 화면에서 저장한 기록과 얼굴 사진을 확인하고 날짜별 기록을 삭제할 수 있습니다. 날짜별 기록 삭제 시 연결된 얼굴 사진과 계산된 참고 수치도 삭제합니다. 설정의 ‘모든 기록 및 사진 삭제’는 모든 기록·얼굴 사진·계산된 참고 수치·설정을 삭제합니다. 같은 날짜를 다시 촬영해 저장하면 기존 기록과 연결 사진을 삭제하고 새 기록으로 교체합니다. 기기 파일 접근 오류로 삭제가 지연되면 앱은 삭제 대기 항목을 남겨 다음 실행 시 다시 삭제를 시도합니다. 기기에서 앱을 ‘삭제’하면 앱 전용 저장 공간의 데이터도 제거됩니다. ‘앱 정리하기’는 데이터를 남길 수 있으므로 앱 삭제와 다릅니다.
