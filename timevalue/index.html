시간값으로 할 수 있는 일

  • 사고 싶은 물건의 이름과 가격을 입력하고 필요한 노동시간을 확인합니다.
  • 월 실수령액, 연봉과 가정한 공제율, 시급 중 내 상황에 맞는 수입 기준을 설정합니다.
  • 근무일수와 근무시간을 반영해 시간과 근무일 기준으로 비교합니다.
  • ‘샀다’, ‘안 샀다’, ‘고민 중’ 판단 기록을 남깁니다. 결정한 기록은 결정 당시 수입 기준을 유지합니다.
  • ‘안 샀다’로 결정한 지출은 사용자가 직접 건너뛴 지출 금액으로 기록해 저축 습관 계획을 돌아볼 수 있습니다. 잘못 기록한 항목은 되돌릴 수 있습니다.
  • 결과를 이미지로 만들어 원하는 경우 직접 공유합니다.

계산은 생활비를 빼기 전 수입 전액을 해당 물건에 쓴다는 가정의 노동량입니다. 실제 구매까지 걸리는 저축 기간이나 줄어든 근무시간을 뜻하지 않습니다. 건너뛴 지출 금액은 사용자가 직접 기록한 값이며, 실제 저축 잔액 또는 금융기관에서 확인된 저축액이 아닙니다. 앱은 자동 이체나 금융계좌 연동을 하지 않습니다. 연봉의 공제율은 사용자가 설정하는 가정이며 세금 계산 결과가 아닙니다.

1. 앱에서 처리하는 정보

시간값은 사용자가 입력한 물건 이름, 가격, 수입, 근무일수·근무시간, 구매 판단, 건너뛴 지출 금액과 관련 기록을 앱 기능 제공을 위해 기기의 앱 저장 공간에 보관합니다. 건너뛴 지출 금액은 사용자가 직접 입력·기록한 값으로, 실제 저축 또는 금융기관에서 확인한 금액이 아닙니다. 회원가입이 필요하지 않으며, 이 정보를 개발자 서버로 전송하거나 개발자가 수집하지 않습니다.

2. 서버, 광고, 분석 도구 및 권한

시간값 앱은 사용자 기록을 저장하는 별도 서버, 광고 SDK, 사용자 행동 분석 SDK를 사용하지 않습니다. 이번 업데이트로 새로 요청하는 기기 권한도 없습니다. 개발자는 앱에 입력된 기록을 열람할 수 없습니다.

3. 기기 백업 및 보관 기간

기기에 저장된 앱 데이터는 iOS 또는 Android 및 사용자의 설정에 따라 운영체제 또는 컴퓨터 백업에 포함될 수 있습니다. 기록은 사용자가 삭제하거나 앱을 삭제할 때까지 기기에 보관됩니다. 앱 ‘정리하기’는 데이터를 남길 수 있으므로 전체 로컬 데이터 제거를 원하면 기기 설정에서 앱을 삭제하세요. 기존 운영체제 백업에 남은 데이터는 운영체제 제공자 및 사용자의 백업 설정에 따라 별도로 관리됩니다.

4. 사용자가 선택하는 이미지 공유

공유 이미지는 기기에서 생성됩니다. 사용자가 직접 운영체제의 공유 기능을 실행하고 대상 앱을 선택한 경우에만 선택한 이미지가 해당 앱으로 전달됩니다. 공유 이미지에는 물건 이름, 가격, 노동시간 및 계산 기준이 포함될 수 있으므로 공유 전에 내용을 확인하세요. 전달 후 정보 처리는 공유 대상 서비스의 정책을 따릅니다.

5. 정보 수정, 되돌리기 및 삭제

수입은 수입 설정에서 수정할 수 있습니다. 고민 중 물건의 입력값은 입력 수정으로 변경할 수 있으며, 개별 기록은 판단 기록의 삭제 기능으로 지울 수 있습니다. 건너뛴 지출 기록은 되돌릴 수 있습니다. 결정한 기록에는 결정 당시 계산 기준이 남습니다. 기기의 모든 앱 데이터는 앱을 삭제하여 제거할 수 있습니다. 운영체제 백업과 외부에 직접 공유한 이미지는 별도로 삭제해야 합니다.
